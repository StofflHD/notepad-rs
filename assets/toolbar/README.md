# Toolbar icons

These icons are the "Fluent UI" toolbar icon set of [Notepad++](https://github.com/notepad-plus-plus/notepad-plus-plus)
(`PowerEditor/src/icons/light|dark/toolbar/regular/*_off.ico`, 32×32 frame), licensed under the
GNU General Public License v3.0 like Notepad++ itself. They were converted from ICO to PNG unchanged;
NotepadRS recolours them at runtime (`src/icons.rs`): the Notepad++ blue becomes the rust accent of
the UI theme and the grey strokes take the theme's text colour.
